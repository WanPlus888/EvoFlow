**电商运营终端 v1.4.2 — 部门群派工条 + 自动回执**

本版相对 **1.4.1**：验收并接线官方部门群派工状态条与终态自动回执；划清与工作台扣费派单 / 草稿工具的边界。

### 新增 / 验收

- **派工条**：@ 气泡下可见排队中 / 回答中 / 已回 / 失败；重挂可回填
- **自动回执**：run / 协作任务终态回群，徽标「自动回执」；开群轻量轮询，不刷屏（固定 message_id）
- **口径**：驾驶舱「生产工单」= 工作台扣费；部门群回执 = 任务结果通报。二者不混

### 边界（红线）

- 部门群回执报告任务结果 **≠** 工作台扣费派单
- `draft_workbench_order` 仍只出草稿，不派单不扣费

### 覆盖安装

从 1.4.1（或 1.4.0）覆盖安装即可。无数据迁移。
