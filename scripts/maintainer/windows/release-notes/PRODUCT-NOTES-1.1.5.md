**电商运营终端 v1.1.5 — 岗位白名单 + 一句话工单草稿 + Gateway 真连**

本版覆盖自 **1.1.4** 以来本机 fork 验收通过的阶段 1 / 阶段 2 合包（前后端同一版本号 **1.1.5**）。

### 新增

- **岗位白名单三岗工具隔离**：套图岗（`tuantu-op`）仅套图相关 `workbench_*`；视频岗（`shipin-op`）仅视频相关；客服对照岗（`kefu-op`）无工作台工具。未授权 / 无配置角色在会话绑定与 worker 继承两条路径上均被剥离（fail-closed）
- **一句话生成工单草稿**：工具 `draft_workbench_order` 将用户一句话解析为结构化工单草稿（类型 / 商品 / 数量 / 预算等）；**只出草稿，不派单、不扣费**；缺字段时提示先确认
- **Gateway 真连工作台**：员工侧商品查询、套图/短视频提交与状态查询经本机 Gateway（`127.0.0.1`）代理到工作台管理员账号；图片预览走 Gateway，不在 EvoFlow 落盘媒体

### 覆盖安装即可

无数据迁移。从 **1.1.4**（或当前本机安装版）覆盖安装至 **1.1.5**。本版自动更新 endpoint 仍指向本机禁用通道时，请用本机打出的 Mac 安装包手动替换「电商运营终端.app」。
