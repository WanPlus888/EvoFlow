# 电商运营终端 1.4.17

**修复：「切换用户」用工台账密登录时提示接口不存在（404）**

- **修复内容**：1.4.16 的安装包里内置网关仍是 1.4.14 旧版，缺 1.4.15 新增的登录统一接口，导致「切换用户」用 AI 工作台账密登录时报「接口不存在」；本版重新打包，内置网关与桌面同为 1.4.17，登录统一恢复可用——工台账密对则进壳、错则提示「用户名或密码不对」，Local Admin 本机运维登录不受影响
- **防复发**：打包脚本新增两道自检——内置网关版本号必须与桌面版本号一致才允许出安装包；且内置网关冷启自测登录接口必须存在（不存在即拒绝打包），此类「桌面升了、内置网关还是旧的」的问题今后会在打包阶段直接报错
- 打包前置自检同步新增残留旧网关检测，把问题拦在打包之前
- 不含 Windows；不自动更新；覆盖安装即可
