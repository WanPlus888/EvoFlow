# 电商运营终端 1.4.13

**运营终端多 Bot 分岗 P0：默认进 Bot 精简聊天 + 专员分岗 + 转交卡 + 投放建议草稿 Gate**

- **打开就是 Bot 聊天**：冷启 / 进运营终端默认进「运营大脑」Bot 精简面（顶条 + 专员条），不再默认全壳首页；点「更多运营能力」随时回全壳，侧栏「回工作台」不变
- **五个专员岗位**：运营大脑（Router，拆需求、按岗转交）、主图·套图专员、工单验收专员、知识沉淀专员、投放盯盘专员；每个岗位只拿到自己的工具白名单（fail-closed），越权工具一律不可用
- **转交卡**：`@专员` 或点专员卡片 → 出转交卡；「确认转交」进入该专员会话（你的诉求已预填好，自己点发送），「取消」留在运营大脑继续聊；转交本身不花钱、不真派
- **投放盯盘只做建议**：盯盘日报 / 异常卡 / 预算·出价·启停建议单全部是本地草稿；「提交人工复核」要点确认卡，且只是给人工复核，**绝不**自动改投放平台（无任何生产写通道）
- **花钱必确认**：套图/视频提交、建议单提交复核均走确认卡；草稿永不自动扣费、不自动派单
- 知识沉淀只有建议草稿，收录需管理员确认；工单验收只出笔记/待办草稿，不关单
- 不含 Windows；不自动更新；覆盖安装即可
